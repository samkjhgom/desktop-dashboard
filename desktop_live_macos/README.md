# macOS 로컬 바탕화면 대시보드

앱 이름/로고 없는 저채도 HUD 인터페이스입니다. **세계지도에서 국가를 클릭**하면 오른쪽 상단 패널에 수도, 인구, 통화, 언어, 시간대가 표시됩니다. 국가를 선택하면 지도가 붉은색으로만 강조되며, 다른 국가들은 어두운 남색과 얇은 회색 경계선을 사용합니다.

## 지도 확대·축소 및 이동

- 지도 위에서 마우스 휠 또는 트랙패드 스크롤: 마우스 위치 기준 확대·축소 (1~8배)
- 지도 오른쪽 위 `+`, `−`: 확대·축소
- `1:1`: 원래 세계지도 배율과 중앙 위치로 초기화
- `Shift`를 누른 채 마우스로 드래그하거나 마우스 가운데 버튼 드래그: 지도 이동
- 확대 중에도 국가를 클릭하면 오른쪽 정보 패널에 표시됩니다.

## macOS에서 실행

Python 3.10 이상과 Tkinter가 필요합니다. ZIP 파일을 압축 풀면 `desktop_live_macos` 폴더가 생깁니다. Mac 터미널에서:

```bash
cd ~/Downloads/desktop_live_macos
chmod +x run_mac.command run_wallpaper_mac.command
./run_mac.command
```

일반 창에서 실행한 뒤 배경화면 모드를 시험하려면 다음 명령어를 사용하세요.

```bash
./run_wallpaper_mac.command
```

배경화면 모드는 macOS 창 레이어/Spaces 구성에 따라 실패할 수 있는 실험적 기능입니다. 실행 시 처음 한 번 Python 라이브러리 설치가 필요합니다. F11 전체 화면 / ESC 종료 / 오른쪽 클릭 메뉴를 지원합니다. 완성형 `.app` 설치 프로그램은 아닙니다.

## 데이터

- **세계지도:** 앱에 포함된 Natural Earth 저해상도 국가 경계 177개. 마우스로 영토를 클릭해 선택합니다. 작고 복잡한 섬/국가의 클릭 정확도에는 한계가 있습니다. 실시간 지리 사건 지도는 아닙니다.
- **국가 정보:** REST Countries API (`restcountries.com`)에서 선택 시 가져오며 로컬에 저장합니다. 인터넷이 없거나 API 요청이 실패하면 기존 캐시가 있으면 표시합니다. 국가 정보의 최신성은 API에 의존합니다. 일부 미승인 지역에는 상세 정보가 제공되지 않을 수 있습니다.
- **CPU/RAM:** `psutil`로 매초 갱신. **배터리:** 센서가 제공되는 Mac에서 배터리 잔량을 표시합니다.
- **환율:** Frankfurter 게시 기준환율. USD/KRW, USD/JPY, 100JPY/KRW. 15분마다 요청합니다. 외환 시장의 초 단위 실시간 호가는 아닙니다.
- **뉴스:** 일본/한국/미국 버튼을 선택할 때만 Google News RSS를 가져와 기사 제목의 키워드/짧은 발췌를 작은 창에 표시합니다. 별도 상세페이지가 열리지 않습니다. 10분 캐시가 있습니다. 일본어/영어 뉴스를 한국어로 자동 번역하지는 않습니다.

## 검증 범위

Python 문법 검사 및 Linux 가상 디스플레이에서 기본 창 실행 점검을 했습니다. 실제 macOS 배경화면 통합과 API 접근은 별도 실기기 검증이 필요합니다.

지리 경계는 Natural Earth Public Domain 자료를 포함합니다 (https://www.naturalearthdata.com/). 온라인 데이터 출처: https://restcountries.com/ , https://frankfurter.dev/ , https://news.google.com/ .
